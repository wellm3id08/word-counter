# Word Counter

Counts the words and characters in any text, as you type. Everything happens in the browser; nothing is sent anywhere. Your text is kept in the browser, so it's still there after a reload.

## Use it

Open `index.html` in any browser, or serve the folder:

```sh
python3 -m http.server
```

Paste or type your text and the numbers update straight away, including an estimate of how long it takes to read.
